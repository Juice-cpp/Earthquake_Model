### Tipos de Commit

| Tipo | Quando usar |
|------|-------------|
| `feat` | Nova funcionalidade |
| `fix` | Correção de erro |
| `refactor` | Reorganização de código |
| `docs` | Documentação |
| `style` | Formatação |
| `perf` | Melhoria de performance |
| `test` | Testes |
| `chore` | Manutenção |
